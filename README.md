# Лабораторна робота №7 — iPhoneHub

Виконав: Томенко Віталій Ігорович, КН-42.

Тема: серверний вебінтерфейс інтернет-магазину iPhone на Laravel Blade із CRUD-операціями, формами та зв'язками Eloquent.

## Реалізовано

- базовий макет `layouts/app.blade.php` із Bootstrap 5, навігацією та flash-повідомленнями;
- перевикористовувані Blade-компоненти полів форми;
- повний SSR CRUD для товарів, категорій, тегів, користувачів, кошиків, замовлень і доставок;
- HTML-форми для зв'язків `1:1`, `1:M` і `M:M`;
- `@csrf` у формах і `@method('PUT')` / `@method('DELETE')` для Method Spoofing;
- серверна валідація, `old()` та відображення помилок біля полів;
- Eager Loading, пагінація та фільтрація каталогу за моделлю, категорією, пам'яттю, кольором, ціною і статусом;
- транзакційне резервування товарів під час створення замовлення;
- одноразове звільнення резерву при скасуванні із збереженням історії замовлення;
- архівування товарів і користувачів, які вже мають історичні зв'язки;
- Feature-тести сторінок, форм, CRUD-операцій та бізнес-правил.

## Перший запуск

```bash
cd php-cicd-lab1
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate:fresh --seed
php artisan serve
```

Відкрити `http://127.0.0.1:8000/`.

## Перевірка

```bash
php artisan migrate:status
./vendor/bin/pint --test
php artisan test
php artisan route:list --except-vendor
```

Очікуваний результат: 42 тести, 170 перевірок і 54 маршрути застосунку.
