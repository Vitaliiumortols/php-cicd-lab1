# PHP CI/CD Lab

Навчальний PHP-проєкт для лабораторної роботи №1
з дисципліни «Веб-програмування».

Мета проєкту — опанувати роботу з Git і GitHub,
налаштувати автоматичну перевірку коду через GitHub Actions
та організувати роботу із задачами через Issues і Projects.

## Запланований функціонал

- Калькулятор із додаванням і відніманням.
- Модульні тести PHPUnit.
- Перевірка форматування коду за допомогою Laravel Pint.
- Автоматичний запуск перевірок для Pull Request і змін у main.
